# Pong - Juego de Arcade en Python

## Descripción

Recreación del clásico videojuego Pong,
desarrollado en Python utilizando turtle.

Dos jugadores controlan sus paletas para
golpear una pelota y conseguir puntos.

## Características

- Juego para dos jugadores.
- Movimiento de paletas mediante teclado.
- Rebotes de la pelota.
- Detección de colisiones.
- Marcador de puntos.
- Reinicio de la pelota después de cada punto.

## Controles

Jugador 1:

- W: Subir
- S: Bajar

Jugador 2:

- Flecha arriba: Subir
- Flecha abajo: Bajar

## Tecnologías

- Python 3
- Módulo turtle

## Cómo ejecutar el juego

1. Tener Python instalado.
2. Descargar el proyecto.
3. Abrir la carpeta en VS Code.
4. Ejecutar:

python main.py
